## Selected Work

### 🔎 [Reliable Korean YouTube Misinformation Detection](https://github.com/rladPsks/youtube-fakenews)
**LLM · Uncertainty Quantification · Conformal Prediction · React/FastAPI**

An uncertainty-aware LLM system that asks not only *what the prediction is*, but **whether it is reliable enough to return**.

- Repeated Qwen3.5-4B inference with answer entropy and TF-IDF reasoning consistency
- Conformal **ACCEPT / ABSTAIN** selective prediction
- Evaluated on **1,435 Korean YouTube transcripts**
- **79.3% → 88.8%** accuracy among selectively accepted predictions
- End-to-end web application + 30-user evaluation

### 🧠 ConFuse — Context-Aware LLM + GBDT Fusion
**LLM · LightGBM · XGBoost · CatBoost · Reliability-aware Fusion**

Personalized sleep-state prediction from lifelog data using structured-data models and LLM-derived context.

- Designed a **sample-wise reliability-guided fusion mechanism**
- Combined structured numerical signals with personalized contextual information
- **Mean binary log loss: 0.6415**
- **ICTC 2026 — Accepted**

### 🧬 Neuron–Astrocyte Transformer
**PyTorch · Transformer · Experimental Design**

Research conducted at the **Korea Institute of Science and Technology (KIST), Brain Science Institute**.

- Extended neuron–astrocyte computation from single-head to multi-head attention
- Implemented comparative experiments in PyTorch
- Designed lesion and control experiments to test robustness and interpretation
